# microCMS 設定

サービス: `SFC-T-Lab-Web` (`t-lab.microcms.io`)

2026-09-23 に、次の5 APIを管理画面で作成した。スキーマは `schemas/` に保存している。

| エンドポイント | 形式 | 用途 |
| --- | --- | --- |
| `tags` | リスト | 記事のタグ |
| `research-areas` | リスト | 研究領域。表示順を指定可能 |
| `members` | リスト | 教員・学生・卒業生。研究領域を参照可能 |
| `posts` | リスト | 研究成果・活動報告・展示／発表。研究領域、タグ、メンバーを参照可能 |
| `site` | オブジェクト | 研究会紹介、対外交流・参加案内、所在地やアクセスの情報 |

日本語の主要項目は必須にし、英語は任意にした。英語が未入力の場合はフロントエンドで日本語にフォールバックする。記事・メンバーなどの公開／下書きはmicroCMS標準のステータスを使う。メンバーを折りたたんで表示するかどうかは画面側で制御するため、非公開情報をメンバーAPIに登録しない。

既存の `default` APIキーは、コンテンツAPIの公開済みコンテンツGETだけが有効。下書き取得、公開終了コンテンツ取得、POST/PUT/PATCH/DELETE、マネジメントAPI権限はいずれも無効だった。キー自体はこのリポジトリに保存していない。ブラウザから直接取得する設計なら、内容更新時にAstroを再ビルドする必要はない。公開サイトへ接続する際は、公開コンテンツだけにこのキーのアクセスが限られている状態を維持する。

スキーマとAstro側の読み取り表示を実装済み。2026-09-23 に既存の研究領域6件（CG、ドローン、VR / AR / XR、動画・映像、メディア、生成AI）を日英の名称・説明・表示順付きで登録し、公開した。その他の実データはまだ登録していない。研究会で確認された内容から公開し、記事や学生プロフィールを仮の実績として作らない。メールアドレスなどの連絡先は追加していない。

Astroでは `src/cms/client.ts` が公開済みデータをブラウザからGETし、`src/scripts/cms-home.ts` がトップページへ反映する。記事本文は `src/scripts/cms-post.ts` で個別表示する。`.env.local` のキー設定と起動方法はルートの `README.md` を参照。タグは記事に関連付けて初めてトップの絞り込みに表示される。研究領域はCMSの公開済み6件を表示中で、公開済みデータが0件の場合のみ固定の6領域を表示する。

`node cms/create-schemas.mjs` でローカルのスキーマJSONを再生成できる。これらは管理画面の「APIスキーマを定義」からインポートできる形式だが、既存APIに再インポートする場合は登録済みコンテンツへの影響を確認する。
